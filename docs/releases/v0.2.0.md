# QBar v0.2.0

v0.2.0 候选版，尚未发布 Release。

这一版把请求调试常用工具收进 DevTools 面板，保持原生简洁布局，不另开窗口。

## 新功能

- **中文 / English**：在 Settings → General → Language 即时切换并保存语言，首次使用参考浏览器语言；协议、请求/响应原文和生成内容不参与翻译。

- **Settings / About**：面板内设置页，管理主题、编辑模式、默认超时、重定向和历史记录；About 展示项目介绍、版本与文档/反馈入口。

- **Tools → Requests**：从当前页面的网络日志筛选并载入请求，缺失正文时提示，不自动重发。
- **Params**：重复查询参数、启停和删除，与 URL 双向同步，未修改参数保留原始编码。
- **JSON**：校验、格式化、压缩、树与字段复制，保留大整数及重复键，显式写回请求正文。
- **Compare**：固定草稿或已完成请求/响应作为基线，逐项查看差异；实际发送快照与当前编辑分开。
- **JWT**：解码、UTC 时间状态、HS256 / RS256 / ES256 签名校验及手动写入 Bearer。离开工具时清空密钥。
- **Response 结构化**：有效 JSON 默认 Pretty 格式化，也可切换 Tree 折叠结构和 Raw 原文；保留大整数与重复键，Copy body 复制原始正文。
- **Raw 高亮**：HTTP 与 JSON 明暗配色，保留原生编辑、复制和撤销；大请求退回纯文本。

SQLi、XSS、LFI、SSRF、SSTI、Shell、Test 统一收进 **Payloads**；自定义片段与请求历史保留。

## 体验细节

- 主题增加跟随系统并实时响应变化，语言可跟随浏览器；跨面板同步外观而不改请求草稿。保留旧偏好，保存失败给出反馈。
- 新用户默认关闭自动渲染到页面；补齐输入属性、窄屏、键盘焦点和系统可访问性设置。

## 视觉细节

- 工作台统一明暗语义色、28px 控件与键盘焦点，主要操作和辅助工具分层；Utilities（⋮）保留编码、哈希、Payloads、自定义片段。
- Settings / About 统一导航、分组、说明层级和链接行；JSON 树补齐语法色与按需显示的复制操作。

## 修复

- 修改捕获正文后不再携带旧消息长度头，避免截断正文。
- 保存的 Raw / Follow redirects 设置在初次 Load 前恢复，避免把设置恢复误判为用户编辑。
- 设置存储读取失败时仍可启动，关闭中的面板不会创建延迟连接。
- JSON 工具首次打开时读取最新正文，切换页签后保留工具编辑。
- 打包校验当前版本、浏览器 Manifest、必要资源与预览代码隔离。

## 安装与升级

候选安装包为 `QBar-chrome.zip`、`QBar-firefox.zip`，附 `SHA256SUMS.txt`。Chrome 解压后通过开发者模式加载；升级时替换原目录内容、重新加载扩展并重新打开 DevTools。保留原扩展目录以继续使用原本的本地设置与历史。

没有新增扩展权限或运行依赖。浏览器托管的协议、Cookie 与受限请求头仍遵循既有规则；工具载入、格式化、恢复历史均不自动发送。

Firefox 包未签名，仅供临时加载。具体验收范围见本地验证记录；构建成功不等同于真实 Firefox UI 验收。
