# v0.2.0 体验核对

本轮聚焦已有功能的默认行为、偏好和可访问性，不新增扫描、身份或转包模块。

| 问题                               | 本轮处理                                                                           |
| ---------------------------------- | ---------------------------------------------------------------------------------- |
| 主题只在启动时读取系统外观         | 新增跟随系统 / 浅色 / 深色；跟随时监听系统变化，无需刷新。                         |
| 固定主题和系统主题混在一个布尔值里 | 使用 `uiThemeMode`；旧 `darkThemeEnabled` 映射到原有手动选择，新用户默认跟随系统。 |
| 偏好加载慢时覆盖刚选的主题         | 用户操作优先，迟到的读取结果不回滚新选择。                                         |
| 多面板外观不一致                   | 主题、语言通过本地存储变化同步；请求草稿、超时和发送状态不跟着其他面板改变。       |
| 语言只有固定中文或英文             | 增加跟随浏览器语言；保留明确选择，自动模式响应 `languagechange`。                  |
| 保存失败没有明确反馈               | 主题菜单与设置页都反馈，失败保留当前选择并提供重试说明。                           |
| 快速连续选择存在写入顺序问题       | 主题、语言、请求默认项、响应显示偏好各自串行写入；旧任务不覆盖新提示。             |
| 收到响应直接改变被检查页面         | 新用户默认关闭自动渲染；已保存的显式选择继续保留。手动渲染仍可用。                 |
| 自动渲染开关含义不清晰             | 更名为「自动渲染到页面」，明确说明会替换被检查页面内容。                           |
| 协议字段受到拼写和自动填充干扰     | URL、正文、请求头与 Raw 编辑器显式关闭拼写、自动大写和自动填充。                   |
| 键盘与系统可访问性适配不足         | 链接补齐可见焦点；高对比模式保留焦点与选中边界；减少动态效果时关闭不必要的过渡。   |
| 窄面板挤压与无效操作占位           | 地址栏和状态栏可换行；Raw 模式收起仅适用于 Basic 的拆分按钮；设置沿用窄屏导航。    |

## 验收规则

1. 系统明暗往返切换时，自动模式实时跟随，固定模式保持不变。
2. 重开面板保留选择；旧配置升级保留原偏好；读取或保存失败仍可编辑。
3. 两个面板修改主题 / 语言会同步，另一面板的请求内容不变、不发送请求。
4. 新用户发送后只在 QBar 内显示响应；自动渲染是明确的可选行为。
5. 键盘导航、Esc 返回、主题菜单选中态、窄屏滚动与明暗高亮保持可用。
6. 卸载时移除媒体查询、存储和浏览器语言监听器，不留下延迟 UI 更新。
