# QBar 标识

QBar 的 Q 由蓝色圆角框与绿色出站箭头组成。圆角框代表请求工作区，箭头把 Q 的尾部与发送动作结合；不使用放大镜圆环、背景磁贴、渐变或投影。

- 主色：`#4285f4`；辅助色：`#34a853`。
- 源文件：`public/icon.svg`，128 × 128 画布，透明背景。
- 扩展资源：`public/icon.png`，由同一 SVG 渲染为 128 × 128 RGBA PNG。
- About 直接引用 SVG；扩展 Manifest 和 DevTools 面板引用 PNG，沿用现有入口与权限。
- 最小显示尺寸 16px；图形周围保留至少画布宽度的 1/8 空白。
- 仓库标题使用 `docs/assets/qbar-header.svg`，图形与扩展保持一致。

保持图形比例，不额外添加圆角背景、不旋转图形，不替换成字体字符 Q。亮色与暗色背景使用同一透明标识。
